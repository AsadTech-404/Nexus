Nexus – Investor & Entrepreneur Collaboration Platform
Nexus is a full-stack collaboration platform designed to bridge the gap between Investors and Entrepreneurs. It provides a centralized hub for scheduling meetings, real-time communication via video calls, and secure document management with e-signatures.

🚀 Features
1. Secure Authentication & Profiles (Milestone 1-2)
JWT-Based Auth: Secure login and registration.

Role-Based Dashboards: Distinct interfaces for Investors and Entrepreneurs.

Profile Management: Customizable bios and investment/startup history.

2. Real-Time Collaboration (Milestone 3-4)
Meeting Scheduler: Calendar integration for booking pitches and consultations.

Video Calling: Peer-to-peer video calls using WebRTC and Simple-Peer.

Signaling Server: Real-time handshake management via Socket.io.

In-App Messaging: Real-time chat with emoji support.

3. Document Chamber (Milestone 5 - In Progress)
File Uploads: Secure PDF/document handling.

E-Signatures: Integrated signature pad for digital agreements.

🛠 Tech Stack
Frontend:

React.js (TypeScript)

Tailwind CSS (Styling)

Lucide React (Icons)

Socket.io-client / Simple-Peer (WebRTC)

Backend:

Node.js & Express

MongoDB (Mongoose ODM)

Socket.io (Real-time signaling)

Multer (File Processing)

⚙️ Installation & Setup
Prerequisites
Node.js (v16+)

MongoDB Atlas account or local instance
